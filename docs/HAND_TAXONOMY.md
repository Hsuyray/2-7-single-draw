## 0. 規則依據

`docs/game_rules.md` 是空檔案 [確認],所以規則以 `solver/hand_evaluator.py` 為準:
- 牌小者勝;A 只當大牌(A-5-4-3-2 是 A 高，不是順子);順子、同花算壞牌。
- 最強是不同花的 7-5-4-3-2。
- 牌力只取決於點數和是否同花，所以兩套分類都只看這兩樣，組合數可以精確計算。

## 1. 兩套分類
- **predraw**:換牌前的起手牌。pat 牌依最高兩張分格;其他牌依「可以抽的牌型」分格。
- **postdraw**:換牌後的最終牌力。

每一手 5 張牌在每套分類中**恰好落在一格** [確認，測試涵蓋全部點數組合與同花與否]。

## 4. 和 solver 抽象的對應

### 4.1 postdraw:bucket 0 合併了 7-5 到 9-6 [確認，結構];影響 [推測]
`PostdrawStrengthBucket` 的 bucket 0 同時包含 7-5、7-6、8-5、8-6、8-7 和部分 9-6。換牌後下注時，最強的 7-5-4-3-2 和 9-6-x-x-x 用同一個策略。原因是 128 個 bucket 在每個類別內依出現頻率切分，強牌稀少，所以全擠在一起。

[推測] 這對 postdraw 的價值下注 / 跟注影響很大，屬於 **B3**(postdraw 策略品質)要量化的問題;D3 不改 bucket。產品顯示時，7-5 和 9-6 會顯示同樣的頻率，要在 UI 上說明。

### 4.2 predraw:`DrawHandBucket` 有 208 / 1,068 個跨兩格 [確認]
主要原因是 bucket 把 8 和 9 合在一起，而本分類用「≤ 8」決定保留的牌。range 顯示時每手牌仍查自己 bucket 的策略，一格的頻率是格內各手牌依組合數加權的平均，所以這只是解析度限制，不會算錯。

## 6. v1 方向(day68,使用者回覆第 5 題)

你的要求：分格依**換牌機率與組合數**,數學上站得住腳，不依習慣設門檻;要考慮位置與換牌。

### 6.1 先釐清：分格和均衡的抽象是兩件事
- **range grid 只是顯示的分組**。均衡是 solver 以 `DrawHandBucket` / `PostdrawStrengthBucket` 為單位算出來的;每手牌的策略都查它自己的 bucket,分格粗細**不會改變均衡**,只改變匯總顯示的解析度。
- 會影響均衡本身的是 **solver 的抽象**:B2 發現 `DrawHandBucket` 把 8 和 9 合併,D3 發現 postdraw bucket 0 把 7-5 到 9-6 合併。這些要在 B1 / B2 / B3 處理(凍結介面、要重訓)。
- 「幾位玩家、剩餘人數」:trainer 目前只支援單挑(CLAUDE.md 第 1 節),所以位置只有 BTN / BB、剩下的對手固定 1 人。多人桌需要多人的 solver,屬於 E3;分格設計會保留「位置」維度，但多人的部分現在沒有資料可依據。

### 6.2 基礎：精確的換牌結果分佈 [確認，已實作]
`solver/hand_classes.draw_outcome_counts(hand, discards)`:任一手牌、任一種留牌方式，換完後落在每個 postdraw 牌力格的**精確組合數**(包含成對、成順、成同花;自己丟掉的牌不會回到牌堆)。
- 驗證：和暴力列舉每一種補牌完全相同(換 1–3 張，含同花聽牌);換 4、5 張的總數為 C(47, n)。
- 例:2-3-4-7 換 1 張 → 成 7 以下 8/47(四張 5、四張 6)、成對 12/47,和牌理一致。

### 6.3 依節點的分格(提案)
固定門檻(「保留 ≤ 8」「pat ≤ T」「順 / 粗」)全部取消，改成**每個節點依 solver 的實際策略與條件化 range 分格**:
1. **依 solver 在這個節點的換牌張數分**(pat / 換 1 / 換 2 / …),不是依手牌外觀預先決定。位置(先換或後換)、對手換幾張、前面的下注，都已經反映在 solver 的策略裡。
2. **同一個換牌張數內，依換牌品質細分**:用 6.2 的精確分佈，算「依 solver 實際選的留牌方式，換完後的牌力」,例如成 7 以下、成 8 以下的機率與成對 / 成順的機率。
3. **格的邊界依條件化 range 的組合數決定**:每格大致等量(例如等分位數),所以不會再出現一格占 55% 的情況;邊界是資料決定的，不是習慣。
4. 順子聽牌的風險不另設格：它已經在 6.2 的成順機率裡。

需要的前提:D1 的條件化 range(`docs/API.md` 9.2)。所以實作順序是 D1 條件化 range → 本節的依節點分格。

### 6.4 postdraw(第 3 節)
牌力區間是客觀的(evaluator 分數的連續區段，已測試)。格的粗細同樣改依條件化 range 的組合數:例如某節點的 range 大多落在 8-x 到 K-x,就把這段切細，空的區段合併。
